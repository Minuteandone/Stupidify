What is being damaged?

GitHub Pages cannot execute the Python checkpoint surgery engine, so this demo applies deterministic damage to token logits during generation. The desktop/CLI tool modifies actual safetensors weights.

Stupidify browser demo Model files are fetched from Hugging Face and cached by your browser when possible.
